# 📊 Electric Vehicle Market Analysis (Python)

## 🔍 Overview

This project analyzes electric vehicle market trends using Python, Pandas, and Matplotlib.

## 📊 Analysis Performed

* Brand-wise EV sales
* Country-wise performance
* Yearly sales trends
* Impact of fuel prices and charging infrastructure

## 🛠 Tools Used

* Python
* Pandas
* Matplotlib

## 📁 Project File

* Electric_vehicles_analysis_Python.ipynb

## 📈 Key Insights

* BYD leads EV sales globally
* EV adoption is increasing over time
* Fuel prices and infrastructure influence EV demand

## 🚀 Outcome

Performed end-to-end data analysis to extract meaningful insights from EV market data.
